# FB Master

Веб-кабинет на FastAPI (`main.py`, порт из `BO_PORT` в `.env`). Отдельно может использоваться `app.py` (парсер на порту 8765).

## Быстрый старт

1. Python 3.12 рекомендуется (см. комментарий в `requirements.txt`).
2. Виртуальное окружение и зависимости: `pip install -r requirements.txt`, при необходимости `playwright install`.
3. Скопировать переменные окружения: `cp .env.example .env` и заполнить секреты.

Подробности по путям (`DATA_DIR`, браузерные профили, Postgres) — в комментариях внутри `.env.example`.

## Владелец платформы (глобальная админка)

Переменная **`FB_MASTER_OWNER_EMAILS`** — список email через запятую (без пробелов вокруг или с пробелами — обрезаются). Только эти пользователи видят в сайдбаре блок **«Платформа → Админ»** и открывают `/admin/platform` со сводкой по всем организациям и зарегистрированным пользователям. У остальных этот пункт меню не рендерится, а прямой заход на URL даёт **404** (без признаков существования раздела).

## Нейросети (ИИ-агент)

- **OpenAI** и **Google (Gemini)**: ключи задаются в `.env` (`OPENAI_API_KEY`, `GOOGLE_API_KEY`) и/или в системных настройках кабинета.
- **Локальная модель**: отдельных переменных в `.env` не требуется; URL сервера и имя модели настраиваются в интерфейсе кабинета (раздел ИИ-агент). Типичный адрес на той же машине — `http://127.0.0.1:11434`, если вы его не меняли.
