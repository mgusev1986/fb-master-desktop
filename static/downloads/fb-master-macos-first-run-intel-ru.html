SOCMASTER на Mac (Intel) — что сделать по шагам

Вы открыли файл 1. Инструкция.html. В той же папке после распаковки архива лежит ещё один файл с номером в начале имени:

1. Инструкция.html — эта страница.
2. SOCMASTER-…-mac-x64.dmg — установщик для Mac на процессоре Intel (полная версия указана в имени файла).

Обычный порядок: откройте 2. (файл с расширением .dmg) → перетащите SOCMASTER в папку «Программы» (Applications) → запустите программу оттуда.

Если Mac пишет «программа повреждена» или «неизвестный разработчик» — попробуйте 3 шага по порядку. Обычно срабатывает Шаг 1 или 2.

⚠️ Важно: если уже пытались запускать и не сработало: macOS «помечает» приложение после неудачного запуска, и команды ниже могут не помочь. Сначала удалите SOCMASTER из «Программ», очистите Корзину, скачайте установщик заново с сайта — и применяйте шаги ниже к свежему .app.

Шаг 1. Через Finder (правый клик)

  1. В Finder откройте папку «Программы», найдите SOCMASTER.
  2. Правый клик (или Control + клик) по иконке → выберите «Открыть».
  3. В диалоговом окне нажмите «Открыть» ещё раз.

Шаг 2. Если не помогло — через Настройки

  1. Откройте Системные настройки → Конфиденциальность и безопасность.
  2. Прокрутите вниз — там будет надпись «SOCMASTER заблокирован».
  3. Нажмите справа «Открыть всё равно», введите пароль Mac.
  4. Запустите SOCMASTER из Программ.

Шаг 3. Если и это не помогло — через Терминал

  1. Откройте Терминал (Программы → Утилиты → Терминал).
  2. Нажмите «Скопировать команду» ниже, в Терминале вставьте (⌘V), нажмите Enter, введите пароль Mac.
  3. Запустите SOCMASTER из Программ нормальным двойным кликом.

sudo xattr -cr "/Applications/SOCMASTER.app" && sudo codesign --force --deep --sign - "/Applications/SOCMASTER.app"

Команда снимает карантин и ставит локальную ad-hoc подпись — это нужно на свежем macOS (Sonoma / Sequoia / Tahoe), где простой xattr -cr уже недостаточен.

Эта сборка — для Mac с процессором Intel (MacBook 2017–2020, iMac / Mac mini до 2020). Для Mac с чипом Apple Silicon (M1–M4) скачайте отдельную сборку mac-arm64.
