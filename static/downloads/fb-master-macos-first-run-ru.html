SOCMASTER на Mac — что сделать по шагам

Вы открыли файл 1. Инструкция.html. В той же папке после распаковки архива лежит ещё один файл с номером в начале имени:

1. Инструкция.html — эта страница.
2. SOCMASTER-…-mac-arm64.dmg — установщик (полная версия указана в имени файла).

Обычный порядок: откройте 2. (файл с расширением .dmg) → перетащите SOCMASTER в папку «Программы» (Applications) → запустите программу оттуда.

Если Mac не даёт открыть программу (неизвестный разработчик / «повреждено» / Apple не подтвердил файл):

  1. Откройте Терминал (Программы → Утилиты → Терминал).
  2. Нажмите кнопку «Скопировать команду» ниже, затем в Терминале вставьте (⌘V) и нажмите Enter.
  3. Снова запустите SOCMASTER из папки «Программы».

xattr -cr "/Applications/SOCMASTER.app"

Без терминала (иногда помогает):

  1. В Finder откройте папку «Программы», найдите SOCMASTER.
  2. Правый клик (или Control + клик) по иконке → выберите «Открыть».
  3. В окне нажмите «Открыть» ещё раз.

Ещё вариант: Системные настройки (в новых macOS — Системные параметры) → Конфиденциальность и безопасность — после попытки запуска может появиться «Всё равно открыть».

Нужен Mac с чипом Apple Silicon (M1–M4) для этой сборки.
