FB Master — установка на macOS

Если macOS блокирует запуск или пишет, что приложение «повреждено», чаще всего это защита Gatekeeper: система не доверяет неподписанной сборке (типично до настройки подписи Apple Developer и нотаризации).

Шаг 1. Перетащите FB Master.app в папку «Программы».

Шаг 2. Откройте «Терминал» и выполните:

xattr -cr "/Applications/FB Master.app"

Шаг 3. Запустите приложение снова.

Дополнительно (без терминала): правый клик по FB Master → Открыть → в диалоге подтвердить открытие. Либо Системные настройки / Системные параметры → Конфиденциальность и безопасность → после попытки запуска — «Всё равно открыть».

Важно: скачивайте версию под свой Mac — Apple Silicon (M1–M4) или Intel — с страницы покупки; несовпадение архитектуры даёт ошибку «не поддерживается этим Mac».

Публичный релиз без предупреждений: нужны подпись Developer ID Application и нотаризация в Apple (настраивает разработчик при сборке установщика).
