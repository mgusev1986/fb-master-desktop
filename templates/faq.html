{{ t("«Оформление аккаунтов» — что это простыми словами?") }}

У вас есть страница Facebook, и вы хотите, чтобы она выглядела живой{{ t(": были записи в ленте, фото, нормальная шапка. Вручную долго копировать всё с другой страницы.") }}

{{ t("В этом разделе вы даёте программе") }} ссылку на пример — открытую страницу, которая вам нравится (часто это публичный профиль). Программа под вашим именем подготовит похожие записи и картинки (можно почти как у примера, можно «пересказать своими словами» или написать заново с помощью ИИ). Потом она сама будет выкладывать посты не все сразу{{ t(", а") }} с перерывами — днём, с паузами, как обычно делают люди, а не десятью постами за минуту.

Это не «Прогрев аккаунтов». {{ t("Прогрев — когда программа") }} ходит по сайту как человек: лента, группы, немного активности. {{ t("Оформление") }} — когда нужно именно наполнить вашу страницу текстами и картинками по образцу.

Что нажимать по шагам

  1. {{ t("Зайдите в") }} {{ t("«Аккаунты»") }}{{ t(": войдите в Facebook и поставьте этому профилю") }} {{ t("место 1, 2 или 3") }}.
  2. Слева откройте {{ t("«Оформление аккаунтов»") }} {{ t("(иногда заголовок страницы —") }} {{ t("«Оформление профиля»") }}{{ t(", это одно и то же).") }}
  3. {{ t("Вставьте") }} ссылку на страницу-пример{{ t(". Она должна открываться у вас в браузере без секретных настроек — иначе программа не увидит записи.") }}
  4. {{ t("Отметьте галочками:") }} аватар, обложка{{ t(", сколько") }} последних постов взять за образец.
  5. {{ t("Выберите,") }} как писать текст{{ t(": как у примера, чуть по-другому с помощью ИИ или совсем новые тексты по вашей теме.") }} {{ t("Картинки") }} — с примера, из папки на компьютере или вперемешку.
  6. Укажите паузы между постами {{ t("(два числа в часах) или включите «умный» режим и лимит постов в день. Записи обычно выходят") }} {{ t("днём") }}{{ t(", не ночью.") }}
  7. {{ t("Нажмите") }} {{ t("«Запустить оформление»") }}{{ t(". Когда подготовка закончится, под карточкой появится") }} список будущих постов{{ t(". Там же:") }} пауза, продолжить {{ t("или") }} сбросить {{ t("(сброс — начать заново; то, что ещё не вышло в ленту, отменится).") }}
  8. {{ t("Если что-то пошло не так — загляните в") }} {{ t("«Журнал и отчёты»") }} {{ t("(в кабинете может называться") }} {{ t("«История и отчёты»") }}).

Три простых правила. {{ t("Берите только то, на что у вас есть право. Не запускайте оформление по тому же профилю, пока идёт рассылка, прогрев или другая тяжёлая задача — дождитесь конца. Если вы") }} закрыли программу и открыли снова — список запланированных постов не пропадает{{ t(", публикации пойдут дальше сами; если оборвалась самая первая подготовка — нажмите «Запустить» ещё раз.") }}

Чтобы ИИ помогал с текстами, в {{ t("«Настройках»") }} должны быть ключи (это часто делает тот, кто вам настроил программу).

{{ t("«Парсер» (поиск людей) — как собрать список из Facebook?") }}

{{ t("В меню этот пункт называется") }} {{ t("«Парсер»") }}{{ t(", а на странице заголовок может быть") }} {{ t("«Поиск людей»") }} — это одно и то же.

  4. {{ t("Выберите") }} аккаунт Facebook в списке «Аккаунт Facebook» (у кого есть рабочий вход и при необходимости место 1–3 в разделе «Аккаунты»).
  5. {{ t("При необходимости выберите вариант в поле") }} {{ t("«Собирать по языку»") }} — если не уверены, оставьте «Все языки» (быстрее).

Что сделать там: добавьте карточку источника по кнопке создания, вставьте ссылку{{ t(", которую вам дал администратор или продавец, сохраните. Потом вернитесь в «Парсер» и отметьте этот источник для запуска.") }}

{{ t("Ключи ИИ: Google Gemini и OpenAI — где взять и куда вставить (пошагово)?") }}

{{ t("Важно:") }} ключ — как пароль. Не отправляйте его в мессенджерах посторонним. Если в вашей версии SOCMASTER нет раздела «Настройки», передайте ключ администратору — он внесёт его в конфигурацию.

Что такое SOCMASTER?

{{ t("Локальная или серверная панель для работы с Facebook:") }} аккаунты {{ t("(Chromium-профили и сессии),") }} доноры и парсер, {{ t("импорт") }}, база контактов, шаблоны, рассылки и комментинг, режим агента {{ t("(цепочки шагов),") }} мессенджер, {{ t("CRM-воронка") }}, скорость/паузы, журнал и настройки (.env{{ t(", ключи LLM, headless).") }}

{{ t("Поток данных: доноры → парсер → Base FB → импорт → база контактов") }}

{{ t("Доноры") }} — карточки источников (URL друзей / members). {{ t("Парсер") }} крутит Chromium, пишет/дополняет .xlsx в каталоге Base FB и синхронизирует строки в БД. {{ t("Импорт") }} подмешивает внешние CSV/XLSX. {{ t("База контактов") }} — единая таблица людей для рассылок, сценариев и CRM.

{{ t("Facebook-аккаунты: слоты 1–3, прокси, мессенджер") }}

Слоты ограничивают число одновременно «горячих» профилей. Сессия хранится на диске в BROWSER_PROFILES_DIR и дублируется в БД. Проверка прокси (если включена) может ставить на паузу исходящие воркеры. Кнопка «Использовать в Мессенджере» задаёт активный профиль для /messenger2.

{{ t("Оформление аккаунтов — как объяснить пользователю и что смотреть в поддержке") }}

Смысл для человека: по ссылке на открытый профиль-пример программа собирает идеи для постов и картинок, опционально меняет аватар и обложку, затем публикует посты по одному с паузами{{ t(", чтобы страница не выглядела как робот, выложивший всё за минуту.") }}

{{ t("Два этапа.") }} Сначала одна задача «всё подготовить». Потом фоново, раз в минуту-другую, программа смотрит: пришло ли время следующего поста — и если да, запускает короткую задачу «выложить один пост». Очередь с датами хранится на карточке аккаунта{{ t(", не только в журнале задач.") }}

{{ t("Поддержка.") }} {{ t("Нет слота 1–3 или нет входа — объяснить как в разделе «Аккаунты». «Уже занято» — на этом профиле идёт парсер, прогрев, рассылка и т.д.; одна тяжёлая автоматизация на аккаунт.
