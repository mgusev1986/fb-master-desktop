{% if cabinet_client_mode(request) %} Загрузите .txt или вставьте одну строку, как вам её дали. Если строка очень длинная — это обычно уже «готовый» вход; прокси по желанию, но для стабильности лучше указать. Если строка короткая, с двоеточиями (логин, пароль и т.д.) — в поле прокси ниже укажите прокси обязательно. Выберите страну в списке — подстроятся язык и время. Затем на карточке нажмите «Войти в Facebook» (открыть сайт в обычном браузере недостаточно). {% else %} Поддерживаются несколько форматов (в файле или вставкой; лишние строки заголовка в .txt пропускаются, берётся первая подходящая строка, кроме чистого JSON — тогда обрабатывается весь файл):
• Только JSON cookies в .txt: массив [{"name":"…", "domain":".facebook.com", …}, …] или экспорт Playwright {"cookies":[…], "origins":[]} — без логина и пароля в строке, сессия сразу в базу (удобно для выгрузок Cookie-Editor и т.п.).
• Авторизация по cookie (как на витрине): телефон:пароль:User-Agent|[…JSON cookies…] — сессия сразу пишется в базу, в карточке сохраняется User-Agent из строки (пароль шифруется на случай ручного входа). Прокси можно не указывать, но для Facebook лучше сразу задать.
• Классика: логин:пароль:TOTP_секрет:ДД.ММ.ГГГГ — нужен прокси IP:порт:логин:пароль (SOCKS5: префикс socks5://). Пресет региона задаёт locale/TZ; для cookie-импорта UA из файла подставляется после пресета.
Важно: ручной вход в обычном Chrome (в т.ч. инкогнито) не подставляет cookies из файла — сначала импортируйте строку сюда, затем в карточке нажмите «Войти в Facebook»: в окно Chromium подмешивается сессия из базы. {% endif %}
