Supabase Auth (рекомендуемый вход)

Основной способ входа — Google через Supabase (на экране входа одна кнопка «Войти через Google»). Project URL и anon public key: Supabase → Settings → API. Включите провайдер Google в Authentication → Providers; в Google Cloud в Authorized redirect URIs вставьте Callback URL из этого провайдера (копирование из Supabase). Здесь же в Supabase → Authentication → URL Configuration добавьте Redirect URL с путём /auth/supabase/callback для хоста, с которого открываете SOCMASTER (локально и прод). Сервисный JWT в кабинет не вводится — проверка сессии через /auth/v1/user.

Рассылка и прогрев

{% if settings_hide_infra %}

Очередь рассылки и прогрева сохраняется в программе. После закрытия и снова открытия SOCMASTER незавершённые задачи могут остановиться. Если галочка ниже включена, программа сама продолжит рассылку и прогрев с того же места, без кнопки «Продолжить». Сценарии по дням подключаются сами; список чатов в мессенджере при необходимости обновите вручную.

{% if cabinet_automation_auto_resume %} включено — продолжит сама {% else %} выключено — продолжить нужно вручную {% endif %}
{% else %}

Очередь контактов и необработанные шаги хранятся в базе. После обновления или перезапуска сервера прерванные задачи помечаются как остановленные; при включённой опции ниже сервер снова запустит рассылку (комментинг / ЛС) и прогрев с того же места в очереди, без ручного «Продолжить». Сценарии по дням подхватываются фоновым тиком; синхронизацию списка чатов мессенджера при необходимости запустите вручную.
